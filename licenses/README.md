# Dependency license sources

`remark-math.txt` is the MIT license from the upstream `remarkjs/remark-math` repository at the `6.0.0` tag (commit `d5d0660b150810a535bbb07eac6cc96a4510aa24`):
https://github.com/remarkjs/remark-math/blob/d5d0660b150810a535bbb07eac6cc96a4510aa24/license

The npm package omits that file. All other runtime dependency license texts are read from the installed packages locked by `package-lock.json`. The build embeds complete notices in `main.js` so that the three-file Obsidian installation retains attribution.
