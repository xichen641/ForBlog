# 开始写作

将这篇笔记复制到测试 Vault，在 Obsidian 命令面板执行「ForBlog：设置当前笔记的发布属性」，再检查和预览。

普通 Markdown、表格和代码块会交给 Hexo 渲染：

```python
print("Hello, blog!")
```

图片可以从 Vault 拖入。插件会处理 `![[图片.png]]`，并只复制本篇实际引用的附件。
