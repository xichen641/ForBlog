ForBlog 0.3.0：文章可见性管理与社区上架准备。

## 更新内容

- 支持单篇及批量设置公开 / 隐藏，兼容 ForBlog 文章和已有 Hexo 文章；隐藏保留源码，增量同步不会意外恢复公开。
- 可见性操作校验引用和陈旧状态，失败后可重试部署；下架继续保留 Obsidian 原稿。
- 文章选择框仅通过颜色变化表达状态，解决对钩错位。
- 完善中英文文档、首次安装配置、权限说明、许可证与自动发布校验。

## 安装与升级

下载本页 `main.js`、`manifest.json`、`styles.css`，放入 Vault 的 `.obsidian/plugins/forblog/`，然后在第三方插件设置中启用。也可下载 `forblog-0.3.0.zip`，解压其中的 `forblog` 文件夹。

升级前先禁用插件，只替换三个安装文件并保留 `data.json`，再重新启用。

## 兼容性

Obsidian **桌面端 1.14.4+**，外部 Node.js **20+**、Git，以及已安装依赖的本地 Hexo 博客。Windows 已做真实窗口验收；macOS / Linux 尚未做真实桌面验收，不支持移动端。集成测试使用 Hexo 7.3.0、Fluid 1.9.8。

最低版本由未经验证的 1.5.0 收紧至实际验收版本 1.14.4。可见性完整变更流程在临时博客与本地 Git 远端测试，真实用户文章未用作破坏性测试。

这是 GitHub Release，尚不表示插件已通过 Obsidian 社区审核。隐藏或下架不清除 Git 历史及第三方缓存中的旧内容。
