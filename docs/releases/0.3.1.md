ForBlog 0.3.1：macOS 兼容性与正文快照修复。

## 更新内容

- 修复阅读视图可能发布隐藏编辑器旧正文的问题，改为读取 Vault 最新内容；编辑模式继续优先使用尚未落盘的编辑器内容。
- 修复 macOS / POSIX 取消和超时后过早报告进程清理完成的问题，等待进程组退出，最多 5 秒。
- 设置页按操作系统展示博客、Node.js 和 Git 路径示例，补充 macOS 安装和验收说明。
- 增加两个正文快照回归测试，并将 CI 扩展为 Windows / macOS × Node.js 20 / 24。

## 安装与升级

下载 `main.js`、`manifest.json`、`styles.css` 到 Vault 的 `.obsidian/plugins/forblog/`，也可解压 `forblog-0.3.1.zip` 中的 `forblog` 文件夹。

升级时先禁用插件，替换三个文件并保留 `data.json`，再重新启用。0.3.0 的安装包不包含本次修复。

## 兼容性与验证范围

- Obsidian **桌面端 1.14.4+**，外部 Node.js **20+**、Git，以及已安装依赖的本地 Hexo 博客。
- Windows 与 macOS Apple Silicon 已有真实窗口验收；Linux 和 Intel Mac 尚未进行真实桌面验收，不支持移动端。
- 65 项自动测试涵盖真实临时 Hexo / Fluid、本地 Git 发布、取消清理、增量同步和文章管理。
- Mac 通过 Dock 启动 Obsidian 时，PATH 可能与终端不同，建议将 `command -v node` 和 `command -v git` 的输出配置为程序绝对路径。

本次验收中的发布操作面向临时本地 Git 远端；GitHub Release 不代表已通过 Obsidian 社区目录审核。
